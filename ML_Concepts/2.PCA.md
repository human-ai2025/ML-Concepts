## Geometric Intrtion 

How to know if a column is important or not?
1. Data spread of that particular column (varience)

If the varience of data is more or less the same then feature extraction comes into picture. 

What PCA does is, 
1. it creates a new subset of features and chooses the most important features from the subset. 
2. It creates new features by changing the axis of rotation and the new PCA(Each feature has a new PCA), after that it see the varience of each PCA.

## Covariance and Coravience Matrix 
Varience will give the value of projection on different axis but it wont give the relationship between different axis. So to get the relationship between the axis we have the concept of covarience. 

Corelation and covarience is the same concept. 
Covarience can be any value or coorelation varies between -1 and 1. 

## Eigen Vectors and Eigen Values 
Matrices are basically linear transformations which causes changes in coordinate system. 
Te number of vector space wil give the number of eigen vectors. 

2d vector space will give 2 eigen vector 
3d vector space will give 3 eigen vector and so on 

Eigen vectors are those vectors whose dirrection wont change irrespective of any linear transformation. 

Eigen Values - How much the eigen vector is streaching.

The largest eigen vector of the covarience matrix always points into the direction of the largest varience of data and the magnitute of this vector equal corresponding eigen value. The second largest eigen vector is always othogonal to the largest eigen vector and points into second largest spread of data.
