Normally in dataset the columns are called the features which is also called dimentionatality. 
So in pratice it is found to be that if we keep on increasing the features, the model metrics that we care for wont increase but can decrese and it also increases the model complexity. So its is prefered to take the optimal features i.e. neight too high nor too less and the ones which make an inpact. 

But why does data being on higher dimentions cause problems?
Answer-> Sparsity. 

In short the line/plane/n-1 seperating the classes is very inefficitive in higher dimentions. 

So basically in higher dimention, the same class points are distant to each other and the different class points are also distant to each other which causes the hyperplane to be inefficitive.  

Cons:- 
1. Performance Decreases 
2. Computation Increases
